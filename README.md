## Structure
Each project is organized as a self-contained Java project with its own source code, documentation, and supporting files.

Project structure may vary based on the project's scope and requirements. Smaller projects may keep Java source files at the project root, while more structured projects may organize source code under `src/` and include additional files or directories when needed.

Each project includes its own `README.md` with project-specific documentation, including setup, compilation, and run instructions where applicable.

Compiled output (`*.class`) and other generated files are excluded from version control through the root `.gitignore`.
